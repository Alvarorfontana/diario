# Banco de personajes — Diario Federal

Ruta: `/banco-personajes/`

Biblioteca demostrativa de avatares ficticios con filtros por categoría y búsqueda. Los avatares iniciales usan DiceBear como proveedor de ilustraciones SVG. No son retratos fotográficos ni imágenes de personas reales.

## Uso editorial
- Exclusivamente para ilustraciones, pruebas de interfaz y recreaciones identificadas.
- No atribuir nombres, citas, testimonios, cargos o hechos a estas identidades.
- No usar para representar a funcionarios, entrevistados, periodistas o fuentes reales.
- La página lleva `noindex,nofollow` y contiene un aviso de uso responsable.
